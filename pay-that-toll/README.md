# Pay That Toll — 키네틱 타이포 가사 데모

OneRepublic "Pay That Toll"(122 BPM)에 맞춘 비공식 키네틱 타이포그래피 가사 영상 데모입니다. 파일 하나(`index.html`)로 동작하고, 빌드 과정이 없습니다.

가사와 음원은 저장소에 넣지 않습니다. 페이지가 실행될 때 사용자가 가진 `.mp3`와 `.lrc` 파일을 브라우저 안에서만 읽습니다.

## 실행 방법

| 방법 | 순서 |
|---|---|
| 파일 직접 열기 | `index.html`을 Chrome/Edge로 열기 → MP3와 LRC를 화면에 드롭 → **재생** |
| 자동 불러오기 | `media/song.mp3`, `media/lyrics.lrc`를 넣고 `npx serve pay-that-toll` 실행 → 브라우저에서 열면 두 파일이 자동으로 들어감 |

`media/` 폴더는 `.gitignore`에 들어 있어 커밋되지 않습니다.

## 단축키

| 키 | 동작 |
|---|---|
| Space | 재생 / 일시정지 |
| ← → | 5초 이동 |
| `[` `]` | 싱크 보정 ±10ms (Shift와 함께 누르면 ±50ms) |
| F | 전체화면 |
| H | HUD 켜기/끄기 |
| R | 처음으로 |

하단 바의 **FLASH**를 끄면 마디마다 바뀌는 색 반전, 화면 흔들림, 글리치가 약해집니다. 시스템에서 "동작 줄이기"를 켜 두면 처음부터 꺼진 상태로 시작합니다.
**REC**(Chrome/Edge)는 처음부터 끝까지 재생하면서 화면과 소리를 `.webm`으로 저장합니다.

## 싱크 기준

- 비트 그리드: 첫 다운비트 0.38초, 실측 121.71 BPM
  (122 BPM으로 계산하면 곡 끝에서 약 0.3초 밀립니다. 화면의 BPM 표기는 122 그대로입니다.)
- 곡 구조(마디 기준): 1절 0 · 프리코러스 8 · 코러스 16 · 포스트코러스 24 · 2절 32 · 프리코러스 40 · 코러스 48 · 포스트코러스 56 · 브레이크다운 64 · 파이널 코러스 72 · 아웃트로 82
- 줄 시간은 LRC 타임코드를 쓰고, 단어 시간은 16분음표 그리드에 맞춰 자동으로 나눕니다. `<mm:ss.xx>` 단어 태그가 있는 확장 LRC를 넣으면 그 시간을 그대로 씁니다.

값은 `index.html` 맨 위 `SONG`과 `SECTIONS`에서 바꿀 수 있습니다.

## 레이아웃

가사에 들어 있는 단어를 보고 줄마다 레이아웃을 고르고, 해당 단어가 없으면 섹션별 목록에서 순서대로 고릅니다.

| 레이아웃 | 모티프 | 고르는 기준 |
|---|---|---|
| roulette | 룰렛 휠, 원형 가사 | black, red |
| clock | 시계, 비트마다 움직이는 분침 | time, clock |
| gauge | 속도계, 호를 따라 쓴 가사, 크래시 | fast, hell, wreck |
| road | 도로 노면 표시, 원근 | road, burn |
| tape | 출입 금지 테이프 | line, cross |
| sign | 고속도로 표지판 (EXIT 122) | sign, exit |
| split | 큰따옴표, 세리프 이탤릭 인용 | 따옴표가 있는 줄, slow |
| ticket | 톨게이트 영수증 + PAID 도장 | money, free |
| stack / marquee | 포스터형 적층 / 가로 띠 | toll, pay 및 섹션 기본 |
| burst | 글자 터널 | oh, ooh만 있는 줄 |
| slam | 한 단어씩 크게 | 섹션 기본 |

단어 효과: bell(링 파동), coin·pay(동전), well(물결), fast(속도선), wreck(유리 깨짐·글리치), burning(불씨), toll(차단기 + PAID 도장).
