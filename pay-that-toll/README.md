# Pay That Toll — 키네틱 타이포 가사 데모

OneRepublic "Pay That Toll"(122 BPM)에 맞춘 비공식 키네틱 타이포그래피 가사 영상 데모입니다. 파일 하나(`index.html`)로 동작하고, 빌드 과정이 없습니다.

가사와 음원은 저장소에 넣지 않습니다. 페이지가 실행될 때 사용자가 가진 `.mp3`와 `.lrc` 파일을 브라우저 안에서만 읽습니다.

## 버전

| 파일 | 스타일 |
|---|---|
| `index.html` (v1) | 도로 표지판·룰렛·영수증 같은 12가지 풀스크린 타이포 레이아웃이 줄마다 바뀌는 강한 그래픽 |
| `v2.html` (Road Trip) | 해 질 녘 → 밤 → 새벽 → 낮 → 노을 → 불꽃놀이 밤으로 이어지는 드라이브 한 편. 하늘 위에 단어가 뜨고, 단어에 맞는 오브젝트가 장면에 등장 |
| `v3.html` (Cost Function) | 검은 바탕 + 제도용 격자 + 주황 불꽃. 도면·등고선 지형·소용돌이·프롬프트 터미널·각도기·신호선 6개 장면을 화면 전환과 카메라 무빙으로 잇는 기술 도면 스타일 |

두 파일은 음원·가사 불러오기, TAP SYNC, 단축키, REC가 같습니다.

### v3 연출 (Cost Function)

요금(toll)을 비용 함수로 보고, 곡을 설계 도면과 계산 과정처럼 보여 줍니다.

| 장면 | 내용 | 주로 쓰이는 줄 |
|---|---|---|
| DRAFT | 격자 위에 불꽃 펜이 톨게이트·동전·자동차·종·우물·시계·나무·표지판·룰렛·집을 그림. 왼쪽 위 TikZ 코드가 한 줄씩 써지고, 치수선·각도·반지름 표기, 오른쪽 아래 도면 표제란(TITLE / DRAWN / CHECKED / SCALE / SHEET) | 돈·나무·요금 |
| TERRAIN | 3D 등고선 지형 위를 카메라가 비행하고, 주황 경로를 따라 글자가 불꽃 뒤에 누워서 이어짐. 속도 단어에서 가속 | 도로·속도·불타는 길 |
| VORTEX | 깔때기 격자와 소용돌이 유선, 테두리를 따라 누운 입체(돌출) 글자. 부르기 전 글자는 외곽선만. 카메라가 주위를 돎 | 우물·동전·충돌 |
| PROMPT | 나이테 파문, 타이핑되는 프롬프트 박스(토큰 번호), p( next \| context ) 확률표가 다음 단어를 "sampled"로 뽑음. 요금 줄에는 유리 막대가 지나감 | 대사·"무언가/아무것도/모든 것" |
| ORBIT | 각도기 눈금·반지름 표기·회전 팔(종이면 진자, 시간이면 시계바늘, 룰렛이면 칸), 원 둘레에 단어 배치 | 시간·종·룰렛·선을 넘는 줄 |
| SIGNAL | 수십 줄의 파형이 솟아올라 단어 모양이 됨(재생 중엔 실제 음원 주파수 반영) | "oh-oh" 후렴·요금 |

- **화면 전환 8종:** 줌 관통, 휩팬, 격자 열림, 글리치 슬라이스, 아이리스, 롤, 플래시, 포커스 블러. 섹션이 바뀌는 줄은 줌 관통.
- **카메라 7종:** 푸시인, 풀아웃, 좌우 팬, 틸트, 롤, 핸드헬드. 강조 단어에서 크래시 줌이 들어가고, 비트마다 미세하게 흔들림. 3D 장면은 별도로 비행·궤도 카메라.
- **오버레이:** 코너 브래킷 HUD, 필름 입자, 가장자리 색수차, 코러스 다운비트의 주황 빛 번짐.
- 같은 장면이 다시 나오면 카메라 높이·궤도·배경 모양이 바뀝니다. 느린 기기에서는 선 개수를 자동으로 줄입니다.

## 실행 방법

| 방법 | 순서 |
|---|---|
| 파일 직접 열기 | `index.html`을 Chrome/Edge로 열기 → MP3와 LRC를 화면에 드롭 → **재생** |
| 자동 불러오기 | `media/song.mp3`, `media/lyrics.lrc`를 넣고 `npx serve pay-that-toll` 실행 → 브라우저에서 열면 두 파일이 자동으로 들어감 |

`media/` 폴더는 `.gitignore`에 들어 있어 커밋되지 않습니다.

## 단축키

| 키 | 동작 |
|---|---|
| Space | 재생 / 일시정지 |
| ← → | 5초 이동 |
| `[` `]` | 싱크 보정 ±10ms (Shift와 함께 누르면 ±50ms) |
| F | 전체화면 |
| H | HUD 켜기/끄기 |
| R | 처음으로 |
| T | TAP SYNC 켜기/끄기 |
| S | 재생 속도 1× → 0.75× → 0.5× |

하단 바의 **FLASH**를 끄면 마디마다 바뀌는 색 반전, 화면 흔들림, 글리치가 약해집니다. 시스템에서 "동작 줄이기"를 켜 두면 처음부터 꺼진 상태로 시작합니다.
**REC**(Chrome/Edge)는 처음부터 끝까지 재생하면서 화면과 소리를 `.webm`으로 저장합니다.

## 싱크 기준

- 비트 그리드: 첫 다운비트 0.38초, 실측 121.71 BPM
  (122 BPM으로 계산하면 곡 끝에서 약 0.3초 밀립니다. 화면의 BPM 표기는 122 그대로입니다.)
- 곡 구조(마디 기준): 1절 0 · 프리코러스 8 · 코러스 16 · 포스트코러스 24 · 2절 32 · 프리코러스 40 · 코러스 48 · 포스트코러스 56 · 브레이크다운 64 · 파이널 코러스 72 · 아웃트로 82
- 줄 시간은 LRC 타임코드를 씁니다. 단어 시간은 아래 순서로 정합니다.
  1. TAP SYNC로 직접 맞춘 값 (브라우저에 자동 저장)
  2. 가사 파일의 `<mm:ss.xx>` 단어 태그 (확장 LRC)
  3. 이 곡 전용 탭 싱크 값 (`SONG_WORD_MAP`, 38줄·285단어, 두 번째 탭 싱크 기준): 태그가 없는 원래 LRC를 넣어도 줄 시작 시간과 단어 수가 맞으면 자동 적용. 가사 글자 없이 시간 숫자만 들어 있음
  4. 자동 추정: 음절 수로 나누고, 쉼표 뒤에는 숨 쉬는 간격을 둔 뒤 16분음표 그리드에 맞춤

## TAP SYNC (단어 타이밍 직접 맞추기)

자동 추정은 음절 수에 기댄 근사값이라 단어가 조금씩 빠르거나 느릴 수 있습니다. 귀로 들으면서 단어마다 탭하면 정확해집니다.

1. 재생 중에 **TAP** 버튼(또는 T)을 누릅니다. 위쪽 패널에 다음에 칠 단어가 노란색으로 표시됩니다.
2. 필요하면 **S**로 속도를 0.75× 또는 0.5×로 낮춥니다.
3. 단어를 부르기 시작하는 순간마다 **J**, **Enter**, 또는 화면을 탭합니다.
4. 틀리면 **⌫**로 한 단어 되돌리거나, **←**로 그 줄을 처음부터 다시 합니다. **→**는 다음 줄로 넘어갑니다.
5. 맞춘 값은 즉시 화면에 반영되고, 같은 가사 파일을 다시 열면 자동으로 적용됩니다.
6. **LRC 내보내기**를 누르면 단어 태그가 들어간 LRC가 만들어집니다. 로컬에서는 `*-synced.lrc` 파일로 저장되고 클립보드에도 복사됩니다. 링크 페이지에서는 클립보드로만 복사됩니다. 이 파일을 `media/lyrics.lrc` 자리에 넣으면 다른 브라우저에서도 같은 타이밍으로 재생됩니다.

한 단어의 시간을 바꾸면 그 줄에서 아직 맞추지 않은 뒤쪽 단어도 같은 만큼 함께 이동합니다. 줄의 시작 시간은 첫 단어의 시간을 따릅니다.

값은 `index.html` 맨 위 `SONG`과 `SECTIONS`에서 바꿀 수 있습니다.

## 레이아웃

가사에 들어 있는 단어를 보고 줄마다 레이아웃을 고르고, 해당 단어가 없으면 섹션별 목록에서 순서대로 고릅니다.

| 레이아웃 | 모티프 | 고르는 기준 |
|---|---|---|
| roulette | 룰렛 휠, 원형 가사 | black, red |
| clock | 시계, 비트마다 움직이는 분침 | time, clock |
| gauge | 속도계, 호를 따라 쓴 가사, 크래시 | fast, hell, wreck |
| road | 도로 노면 표시, 원근 | road, burn |
| tape | 출입 금지 테이프 | line, cross |
| sign | 고속도로 표지판 (EXIT 122) | sign, exit |
| split | 큰따옴표, 세리프 이탤릭 인용 | 따옴표가 있는 줄, slow |
| ticket | 톨게이트 영수증 + PAID 도장 | money, free |
| stack / marquee | 포스터형 적층 / 가로 띠 | toll, pay 및 섹션 기본 |
| burst | 글자 터널 | oh, ooh만 있는 줄 |
| slam | 한 단어씩 크게 | 섹션 기본 |

단어 효과: bell(링 파동), coin·pay(동전), well(물결), fast(속도선), wreck(유리 깨짐·글리치), burning(불씨), toll(차단기 + PAID 도장).
